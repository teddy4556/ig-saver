# IG Saver

一个精简的 Instagram 媒体下载油猴脚本,单文件,无依赖。

在 Instagram 页面上直接下载 **原图** 和 **完整视频(含声音)**,不用第三方网站,不用登录额外服务。

## 特性

| | |
|---|---|
| 📸 **原图下载** | 抓最高分辨率原图(实测最高到 3072w),不是 IG 网页上压缩过的预览图 |
| 🎬 **完整视频** | 音视频分离的 Reels 自动合成为单个有声 MP4,不需要手动拼 |
| 📐 **多图轮播** | 一次点下,整组图片全部下载 |
| 🏷️ **智能命名** | 文件名模板可自定义,14 个占位符(作者名 / 短码 / 时间 / 序号 / 原始文件名等) |
| 🧩 **零依赖** | 单个 `.user.js` 文件,不用装任何东西 |
| 🇨🇳 中文界面 | 菜单和提示都是中文 |

## 安装

### 前提

先装 [Tampermonkey](https://www.tampermonkey.net/) 或其他用户脚本管理器(Chrome / Edge / Firefox 都有)。

### 步骤

1. 下载仓库里的 [`ig-saver.user.js`](./ig-saver.user.js)
2. 打开 Tampermonkey 面板 → **添加新脚本**
3. 删掉模板里的全部内容
4. 把 `ig-saver.user.js` 的内容复制进去,按 `Ctrl + S` 保存

装好后打开任意 Instagram 页面,能看到下载按钮就说明成功了。

### 确认装的是新版

按 F12 打开控制台,第一行应该看到:

```
[IG-SAVER-0.3.72] 启动中...
```

版本号对不上就是旧版。

## 使用

### 下载按钮在哪

| 内容 | 页面 | 按钮位置 |
|---|---|---|
| 普通帖子(单图 / 多图 / 视频) | 首页信息流、个人主页 | **图片 / 视频右缘外侧,顶部对齐** |
| Reels 短视频 | `/reels/<id>` | 页面右上角 |
| Stories 快拍 | `/stories/<用户名>/<id>` | 顶部右侧 |
| Highlights 精选 | `/stories/highlights/<id>` | 顶部右侧 |
| 头像 | `/<用户名>/` 个人主页 | 头像右下角 |

> 按钮位置说明:两个按钮竖排贴在图片右缘**外面**的空白边距里,不压住画面内容。图片懒加载时按钮会晚一两秒出现,滚到视野里就会自动挂上。

每个帖子有 **两个** 按钮:

- **↓** 下载当前看到的那一张 / 当前幻灯片
- **↓⇊** 下载这个帖子的全部内容(整组多图 / 完整视频)

### 文件保存到哪

默认进浏览器下载目录,跟你平时下载网页文件一样。

### 改文件名

Tampermonkey 图标 → 菜单 → **📝 设置命名模板**。

可用占位符:

| 占位符 | 含义 | 示例 |
|---|---|---|
| `%USERNAME%` | 作者名 | `chrylvsu` |
| `%SOURCE_TYPE%` | 类型(Post / Story / Reel / Highlight / Avatar) | `Post` |
| `%SHORTCODE%` | 帖子短码 | `DeYvsWNpoud` |
| `%YEAR%` `%2-YEAR%` | 年(4 位 / 2 位) | `2026` / `26` |
| `%MONTH%` `%DAY%` | 月 / 日 | `10` / `12` |
| `%HOUR%` `%MINUTE%` `%SECOND%` | 时 / 分 / 秒 | `16` / `05` / `44` |
| `%ORIGINAL_NAME%` | IG 原始文件名 | `845891782_18136758172` |
| `%ORIGINAL_NAME_FIRST%` | 原文件名第一段 | `845891782` |
| `%INDEX%` | 多图组内序号 | `2` |
| `%UID%` | 作者数字 ID | `1469743772` |

**默认模板**:

```
%USERNAME%-%SOURCE_TYPE%-%SHORTCODE%-%YEAR%%MONTH%%DAY%_%HOUR%%MINUTE%%SECOND%_%INDEX%
```

生成的文件名长这样:

```
chrylvsu-Post-DeYvsWNpoud-20261012_160544_1.jpg
```

也可以做成带文件夹的形式,用 `/` 当分隔符:

```
%USERNAME%/%YEAR%-%MONTH%-%DAY%/%SHORTCODE%_%INDEX%
```

菜单里还有:

- **🔄 重置模板** — 恢复默认
- **🧹 清空 URL 缓存** — 遇到下载到小图/画质不对时试一下
- **🖼️ 开关原图下载** — 默认开启,关闭后走 GraphQL 回退路径
- **⬇️ 开关 GM_download 模式** — 某些浏览器上批量下载更稳

## 常见问题

**Q:点了没反应 / 提示找不到媒体?**

Instagram 偶尔会触发风控。如果同一个页面短时间点了太多次,等几分钟再试,或者把浏览器刷新一下。

**Q:视频下载下来没声音?**

极少数 Reels 本身就没有音轨。正常情况下脚本会自动合成有声 MP4,如果失败会在页面下方提示,并保存成两个文件(视频 + 音频),可以用 ffmpeg 手动合并。

**Q:下载到的图比网页上看到的还大?**

对,脚本抓的是原图。网页上显示的是压缩过的预览版。

**Q:支持哪些浏览器?**

Chrome / Edge / Firefox 的 Tampermonkey 环境都可以。脚本用了 `GM_xmlhttpRequest` 和 `GM_download`,这些是用户脚本管理器的标准能力。
